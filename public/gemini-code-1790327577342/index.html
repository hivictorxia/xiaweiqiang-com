投资的本质是认知的变现#

我相信价值投资不仅仅是一种买卖股票的策略，更是一种认识世界、理解商业运作规律的底层框架。无论是研读巴菲特历年的致股东信，还是拆解企业的自由现金流，核心都是在寻找那些拥有深厚护城河与优秀管理层的长坡厚雪。

在有限的世界里，玩无限的游戏#

除了商业，我也在探索人生设计的命题。有限游戏以取胜为目的，而无限游戏以延续游戏为目的。建立个人系统、沉淀阅读思考、开展研学与教育，都是为了让人生这场无限游戏更加丰满。

欢迎在这个角落，与我一起沉淀常识，探索商业与人生的脉络。
